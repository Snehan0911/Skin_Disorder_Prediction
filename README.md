<h2>📌 Project Overview</h2>
<p>
This project aims to predict six different skin diseases using Machine Learning techniques.
The system analyzes clinical and histopathological features and assists dermatologists in
early diagnosis and decision-making.
</p>
</div>

<div class="card">
<h2>🎯 Problem Statement</h2>
<p>
Diagnosing erythemato-squamous diseases is challenging because multiple skin disorders
share similar symptoms. This project builds an intelligent classification model capable of
predicting the correct disease category with high accuracy.
</p>
</div>
